# opnsense-blue-theme

## Installation

The .txz package can be installed with:

```sh
sudo pkg add https://github.com/trifoil/opnsense-blue-theme/raw/main/os-theme-blue-devel-0.1.txz
```

After installation, a new dark theme should appear in `System` -> `Settings` -> `General` -> `Theme`

## Removal

If you want to get rid of the package:

```sh
sudo pkg delete -y os-theme-blue-devel
```


## Build

```sh
sh build.sh
```
